# ReceiptReady

ReceiptReady is a photo-first expense tracker for small-business owners. Take a picture of a receipt, save it as an expense, categorize spending, mark tax-related costs, and export a clean report for bookkeeping and tax preparation.

## Branches

- `dev` - default development branch
- `release` - protected release branch (pull request + review + CI required)

## Build

```bash
cd code
mvn verify
mvn javafx:run
```
